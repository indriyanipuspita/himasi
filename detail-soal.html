Latihan Soal UAS: Algoritma & Pemrograman

Jumlah Soal: 30

Referensi: Modul Universitas Terbuka

HIMASI

1. Manakah yang termasuk struktur dasar algoritma?
  • A. Runtunan, Pemilihan, Pengulangan
  • B. Runtunan, Percabangan, Array
  • C. Input, Proses, Output
  • D. Main, Function, Procedure
Pembahasan: Tiga struktur dasar algoritma adalah Sequence (runtunan), Selection (pemilihan), dan Repetition (pengulangan).
2. Simbol flowchart berbentuk belah ketupat digunakan untuk...
  • A. Input/Output
  • B. Proses
  • C. Decision (Keputusan)
  • D. Terminator (Mulai/Selesai)
Pembahasan: Belah ketupat melambangkan pengambilan keputusan (Decision) yang biasanya menghasilkan output YA atau TIDAK.
3. Tipe data yang digunakan untuk menyimpan nilai logika benar (true) atau salah (false) adalah...
  • A. Integer
  • B. String
  • C. Boolean
  • D. Char
Pembahasan: Boolean adalah tipe data primitif yang hanya memiliki dua kemungkinan nilai: true atau false.
4. Manakah penulisan variabel yang valid dalam Java?
  • A. 1namaVariabel
  • B. nama variabel
  • C. _namaVariabel
  • D. class
Pembahasan: Identifier boleh dimulai dengan huruf, underscore (_), atau tanda dolar ($). Tidak boleh dimulai dengan angka atau spasi.
5. Operator aritmatika modulo (%) digunakan untuk...
  • A. Pembagian bilangan bulat
  • B. Mendapatkan sisa bagi
  • C. Menghitung persentase
  • D. Perkalian pangkat
Pembahasan: Operator Modulo (%) menghasilkan sisa pembagian dari dua bilangan operandnya.
6. Jika a = 5 dan b = 2, berapakah hasil dari (a > b) && (b < 0)?
  • A. True
  • B. False
  • C. Error
  • D. Null
Pembahasan: (5 > 2) adalah True. (2 < 0) adalah False. True AND False menghasilkan False.
7. Struktur 'if-else' termasuk dalam...
  • A. Looping
  • B. Branching (Percabangan)
  • C. Array
  • D. Method
Pembahasan: If-else digunakan untuk mengarahkan alur program ke cabang kode tertentu berdasarkan kondisi boolean.
8. Pernyataan 'switch-case' paling cocok digunakan ketika...
  • A. Kondisi melibatkan range nilai (misal > 10)
  • B. Kondisi sangat kompleks
  • C. Memilih satu dari banyak opsi nilai pasti (fixed)
  • D. Hanya ada satu kondisi
Pembahasan: Switch-case efektif untuk percabangan multi-arah berdasarkan kesamaan nilai (equality) variabel tunggal.
9. Perulangan 'for' biasanya digunakan ketika...
  • A. Jumlah perulangan belum diketahui
  • B. Jumlah perulangan sudah diketahui pasti
  • C. Kondisi berhenti tidak jelas
  • D. Tidak memerlukan counter
Pembahasan: For loop ideal untuk iterasi yang jumlah perulangannya (count-controlled) sudah ditentukan sejak awal.
10. Apa output dari: int i=0; while(i < 3) { print(i); i++; }
  • A. 0123
  • B. 123
  • C. 012
  • D. Error
Pembahasan: Loop berjalan saat i=0, i=1, i=2. Saat i=3 kondisi i < 3 bernilai salah dan loop berhenti.
11. Array adalah struktur data yang menyimpan elemen dengan tipe data...
  • A. Berbeda-beda
  • B. Sama (Homogen)
  • C. Dinamis
  • D. Abstrak
Pembahasan: Array menyimpan kumpulan elemen yang bertipe data sama dalam urutan memori yang kontigu.
12. Indeks pertama dari sebuah array biasanya dimulai dari angka...
  • A. 1
  • B. -1
  • C. 0
  • D. Bebas
Pembahasan: Dalam bahasa C, C++, Java, dan banyak bahasa modern lainnya, array menggunakan zero-based indexing.
13. Fungsi (function) atau method yang tidak mengembalikan nilai menggunakan keyword...
  • A. null
  • B. empty
  • C. return
  • D. void
Pembahasan: Keyword void menandakan bahwa sebuah method melakukan tugas tertentu tanpa mengembalikan nilai (return value) ke pemanggilnya.
14. Parameter yang dikirim saat pemanggilan fungsi disebut...
  • A. Parameter Formal
  • B. Parameter Aktual (Argumen)
  • C. Variabel Lokal
  • D. Referensi
Pembahasan: Parameter Aktual adalah nilai nyata yang dikirimkan ke fungsi saat dipanggil, sedangkan Parameter Formal adalah variabel dalam definisi fungsi.
15. Algoritma pencarian yang bekerja dengan membagi data menjadi dua bagian secara berulang disebut...
  • A. Linear Search
  • B. Bubble Sort
  • C. Binary Search
  • D. Selection Sort
Pembahasan: Binary Search mencari data pada array terurut dengan membagi interval pencarian menjadi dua bagian setiap iterasinya.
